✨ อัปเดตใหม่ v2.1 Gesture Undo/Redo & เลือกสัดส่วน Widget

เขียน Doodle ไร้กรอบ ลอยบนหน้าจอหลัก

วิดเจ็ตวาดเขียนลายเส้นพื้นหลังใส 100% สำหรับ Android ออกแบบเพื่อ S-Pen โดยเฉพาะ แตะ 2 นิ้วเพื่อ Undo, 3 นิ้วเพื่อ Redo และเลือกสัดส่วนภาพให้พอดีกับขนาด Widget ได้ทันที

ดาวน์โหลด APK ล่าสุด ดูความสามารถทั้งหมด
WIDGET FRAME · 1:1
✌️ 2-finger Undo 🤟 3-finger Redo
✦ S-Pen Pressure Sensitive & Eraser Button

ความสามารถที่ออกแบบมาเพื่อการจดบันทึกจริง

เรียบง่ายแต่ทรงพลัง ตอบสนองเร็ว ไม่กินแบตเตอรี่ และปรับแต่งได้ตามใจ

NEW
✌️

แตะ 2 นิ้ว Undo / 3 นิ้ว Redo

ย้อนกลับและทำซ้ำได้ทันทีด้วย Gesture แตะ 2 นิ้ว หรือ 3 นิ้วบนหน้าจอแบบแอปวาดรูประดับโปร พร้อมระบบตรวจจับล้ำหน้า ป้องกันเส้นเปื้อนเวลาสัมผัส

NEW
📐

เลือกสัดส่วน Widget ได้ตรงใจ

เลือกสัดส่วนได้ทั้ง 1:1 (จัตุรัส 2x2, 3x3), 4:3, 16:9, 2:1 หรือเต็มจอ พร้อมกรอบไกด์ขอบโค้งมน ช่วยให้ภาพวาดพอดีกับขนาด Widget บนหน้าจอโฮมเป๊ะ

NEW
🔄

หมุนจอไม่เบี้ยว (Rotation-Proof)

ใช้ Virtual Canvas สัดส่วนคงที่ ทำให้เมื่อหมุนโทรศัพท์ระหว่างแนวตั้งกับแนวนอน หรือเปิดบนแท็บเล็ต/Galaxy Fold ลายเส้นจะไม่ถูกดึงยืดแน่นอน

✍️

รองรับ S-Pen สมบูรณ์แบบ

ตรวจจับน้ำหนักแรงกดจริง ให้เส้นหนาบางเป็นธรรมชาติ พร้อมตรวจจับปุ่มข้างปากกา Stylus เพื่อสลับเป็นยางลบอัตโนมัติขณะกด

🎨

จานสี 32 เฉด & Toolbar ย้ายได้

จานสีคัดสรร 32 เฉดสีสวยงาม พร้อมแถบเครื่องมือลอยน้ำ (Floating Toolbar) ที่แตะลากย้ายตำแหน่งไปวางมุมไหนก็ได้ ไม่เกะกะพื้นที่วาด

⚡

เซฟไว ไร้สะดุด (Background Save)

ประมวลผลการบันทึกภาพด้วย Kotlin Coroutines แยกจาก UI Thread ป้องกันอาการกระตุก พร้อม Memory Object Pool รองรับ Undo/Redo ลื่นไหล

วิธีเริ่มต้นใช้งานใน 3 สเต็ป

เพียงติดตั้ง APK และแตะเพื่อวาด โน้ตของคุณจะขึ้นบนหน้าจอทันที

STEP 1

ดาวน์โหลด & ติดตั้ง APK

ดาวน์โหลดไฟล์ APK ล่าสุดจากหน้า GitHub Releases และกดติดตั้งลงในอุปกรณ์ Android ของคุณ

STEP 2

วาง Widget บนหน้าจอหลัก

แตะค้างบนหน้าจอโฮม เลือกเมนู Widgets ค้นหา "anndoodle" แล้วลากวางในขนาดที่ต้องการ (เช่น 2x2 หรือ 4x2)

STEP 3

แตะเพื่อวาด & กดเซฟ

แตะที่ตัว Widget เพื่อเปิดหน้าวาด ใช้ S-Pen รังสรรค์ผลงาน แล้วกดปุ่มติ๊กถูก ภาพจะอัปเดตขึ้นหน้าจอหลักทันที!
